# ADR-0007 新组件：受控展示层加独立 Demo

状态：已采纳

## 背景

现有上游组件的数据已经走 props（默认值是演示数据），但状态（例如 ThinkingState 的阶段）由内部定时器推进，外部无法用真实的 agent 事件驱动，也无法表达 error、取消、重试等真实状态。

## 决定

- 新组件由两部分组成：**受控组件**（状态全部来自 props，具名导出，并导出 `Props` 类型）与 **Demo**（默认导出，用定时器和假数据驱动受控组件）。画廊展示 Demo，registry 分发整个文件。
- 目前二者在同一个 `index.tsx` 里；`npm run new` 的模板就是这个形态。Demo 变大时再拆成单独文件。
- 旧组件不一次性重写，在被实际使用或替换时再补成受控形态（见路线图）。

## 后果

- 同一个组件既能在画廊里演示，又能接真实 agent。
- 旧组件短期内仍是定时器驱动，画廊里的状态预览条等依赖受控形态的功能只对新组件可用。

## 备选

保持单文件、靠回调（如 `onSettled`）通知外部。否决：无法表达真实状态。
