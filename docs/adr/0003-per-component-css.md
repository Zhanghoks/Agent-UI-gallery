# ADR-0003 组件独有 CSS 放进各自文件夹

状态：已采纳

## 背景

旧的 registry 脚本用硬编码行号从全局样式里切出 sidebar 与 records 两大块 CSS，改动全局样式前几行就会静默出错；迁移时还发现它把 records 块少切了末尾的 `}`，导致 foundation 多出一个孤立的 `}`。

## 决定

- 独有 CSS 移到组件文件夹的 `styles.css`，在 `meta.json` 里用 `css` 声明。
- `app/globals.css` 只保留 token（`:root`、`.dark`）、`@theme` 映射、基础规则和通用动画，并 import 生成的组件样式汇总文件。
- registry 直接读组件的 CSS 文件（去掉末尾空白并补一个换行），foundation 是去掉生成 import 行之后的全局样式。

## 后果

- 消除脆弱的行号切片，顺带修掉上述孤立的 `}`。
- 新组件可以带自己的样式而不碰全局样式。
- 组件样式在层叠顺序上先于全局 token 之后的规则；目前组件样式都是独立类名，没有观察到冲突。

## 备选

继续用行号或注释标记切片。否决：仍然依赖易碎的文本约定。
