# ADR-0009 画廊外壳保持交互不变，仅开放扩展点

状态：已采纳

## 背景

画廊的交互（左栏导航、卡片内变体切换、复制与查看源码、深浅色）是这个项目最看重的部分，不应因为重构或扩展而改变。

## 决定

- 不改变现有布局与交互；只通过元信息驱动的扩展点增加能力，且按需增量加入。
- 已实现：按分类分组的导航与卡片列表（ADR-0010）、分组标题可作为锚点、滚动高亮跟随分组、卡片在分组内编号、`origin` 标记；左栏的查找辅助（过滤框按标题、说明、id、分类匹配，回车跳到第一个匹配；分类旁的数量；分类可折叠）。Workflow 与 Harness 在页面切换里，旧地址 `/workflow`、`/harness` 转到对应视图。过滤只收窄左栏，卡片不变。
- 未实现：`?variant=` 深链接、受控组件的状态预览条（running / done / error）。这两项记录在路线图里。

## 后果

- 观感稳定，扩展点都由 `meta.json` 与配置驱动。
- 状态预览条要求组件已是受控形态，因此只会对新组件或已改造的组件显示。

## 备选

重做画廊外壳的布局与交互。否决：现有交互是项目最看重的部分。
