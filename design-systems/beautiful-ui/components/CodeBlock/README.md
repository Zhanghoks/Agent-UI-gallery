A line-numbered code listing and a unified diff, with copy.

## When to use

- Variants: `Code` and `Diff`. Set in the mono family; additions `green`, deletions `red`.
- Consumer supplies the lines or diff rows.

## Props

```ts
{ variant, lines, code, diff, filename, labels, onCopy, }: CodeBlockProps
```

Full types: `components/CodeBlock/CodeBlock.d.ts`. Source: `components/primitives/CodeBlock.tsx` in slev12397/beautiful-ui.
