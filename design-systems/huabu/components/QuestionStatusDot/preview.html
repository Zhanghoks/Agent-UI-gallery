A h-1.5 w-1.5 rounded-full dot pinned -right-0.5 -bottom-0.5 on whatever it marks: info running, success with animate-pulse when finished, danger on error. Once a finished answer has been viewed, the dot returns null — the pulse is a summons, and it stops the moment it is answered. It is role="status" with a tooltip and an aria-label, so the state is never carried by colour alone.
