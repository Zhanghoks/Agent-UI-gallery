Spec v3
pdf.js loads lazily — only when an uncached first-page thumbnail is needed. The expanded preview keeps an aspect-ratio placeholder per page and mounts the canvas and text layer only within one scroll viewport, with a six-page LRU. A PDF node is on the binary LOD ladder: below the threshold it is a title.
Extract is base in fg-muted, line-clamp-5. Selection inside the text layer uses pdf-selection-border with a 12% info wash; search highlights paint through the CSS Custom Highlight API at 45% warning-light, diluted again over the glyph bitmap.
