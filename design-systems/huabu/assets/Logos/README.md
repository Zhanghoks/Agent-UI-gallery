# Logos

Both marks are committed SVGs from the repository's `assets/` folder and are used verbatim. They are shown through `<img>`, so they cannot inherit colour — each one carries its own fills and there is no single-ink variant.

`huabu-logo.svg` is the product mark: a 120×120 white rounded square (`radius` 15.27px) holding two `mark-ink` brush strokes and four Microsoft dots — `ms-blue` left, `ms-red` top, `ms-yellow` bottom, `ms-green` right. Because its plate is white it needs no light background of its own, but it must never be recoloured or redrawn, and the four dots are Microsoft's, not part of the UI palette. Use it at 64px in a README header and at 16–32px as an app icon; below 24px the strokes close up, so prefer the dots-only reading only if a smaller mark is ever needed — and ask, rather than cropping this file.

`huabu-collaboration.svg` is the product illustration: one blue person and three coloured agents arranging connected materials in a shared Space. It is the README hero at 800px wide and it is the only illustration in the system. Use it on `bg-surface` or white; do not place it on a tinted surface and do not extract figures from it.
